Schedule Performance Index (SPI) ต่อ Milestone

สูตร: SPI = EV / PV CL/UCL/LCL คำนวณอัตโนมัติ

ใส่ Milestone, EV, PV แล้วระบบจะคำนวณ SPI ให้อัตโนมัติ (EV/PV). จากนั้นคำนวณ CL = ค่าเฉลี่ย SPI, UCL = CL + 3*sqrt(CL), LCL = max(0, CL - 3*sqrt(CL)).

Milestone EV PV SPI (EV/PV) UCL (Auto) LCL (Auto)

ทิป: PV = 0 จะคำนวณ SPI ไม่ได้ (กันหารศูนย์) — จะปล่อยให้ว่างจนกว่าจะใส่ PV มากกว่า 0
