# Wiki Folder Structure

```text
docs/
  README.md
  wiki/
    README.md
    STRUCTURE.md
    developers/
      README.md
    stakeholders/
      README.md
  mvp/
  shared/
  vision/
```

## Maintenance Rules

- ห้ามย้ายไฟล์ source of truth โดยไม่แจ้งทีม
- หน้าใน `docs/wiki/` มีหน้าที่นำทาง ไม่แทนที่เอกสารต้นฉบับ
- เมื่อเพิ่มเอกสารใหม่ ให้เพิ่มลิงก์ใน wiki ที่เกี่ยวข้องทันที
