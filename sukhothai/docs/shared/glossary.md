# Glossary

คำศัพท์กลางสำหรับทีม product/design/code

## Core Terms
- MVP: ขอบเขตที่ต้องส่งมอบเพื่อพิสูจน์ความสนุกและใช้ขอทุน
- Vision: ทิศทางและ backlog ระยะยาว (ยังไม่ commit schedule)
- Content Registry: ทะเบียนรายการ content ที่ล็อก scope พร้อม owner/estimate/status
- Acceptance Criteria: เงื่อนไขที่บอกว่างานชิ้นนั้นเสร็จจริง
