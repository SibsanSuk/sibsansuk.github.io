# Naming Conventions

มาตรฐานการตั้งชื่อเพื่อให้ data/code/assets สอดคล้องกัน

## IDs
- ใช้ `snake_case` ภาษาอังกฤษทั้งหมด
- หลีกเลี่ยง prefix ที่ไม่จำเป็น
- ID ต้อง stable และไม่ reuse

## Examples
- `rice_farm`
- `water_collect_point`
- `crisis_trigger_01`

## File Names
- เอกสารใช้ `kebab-case`
- data key ใช้ `snake_case`
