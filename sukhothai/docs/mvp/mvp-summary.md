# Sukhothai MVP Summary (Pre-Funding)

## 1) เป้าหมาย MVP
- พิสูจน์ว่าเกมมีความสนุกจริงในแกน city-builder
- แสดงเอกลักษณ์ชัด: ไทยยุคสุโขทัย + น้ำ/นา/ศรัทธา
- มีเดโมที่ใช้โชว์นักลงทุน/ผู้สนับสนุนได้ภายใน 10-15 นาที

## 2) ขอบเขต MVP (Must Have)
- 1 แผนที่หลัก: เมืองริมแม่น้ำ
- 12 อาคารหลัก (บ้าน, อาหาร, น้ำ, ตลาด, ศาสนา, ความปลอดภัย)
- 3 ห่วงโซ่การผลิตหลัก: ข้าว, ไม้, เครื่องปั้น
- ระบบบ้าน 3 ระดับตามความต้องการประชาชน
- ระบบทรัพยากรหลัก: อาหาร, ไม้, เงิน, แรงงาน, ศรัทธา
- ระบบวิกฤต 1 แบบ: น้ำท่วมหรือภัยแล้ง
- เงื่อนไขชนะ 1 แบบ + แพ้ 1 แบบ
- UI พื้นฐานเล่นได้ครบลูป (แถบทรัพยากร, เมนูสร้าง, แจ้งเตือน)

## 3) สิ่งที่ยังไม่ทำใน MVP (Not Now)
- แคมเปญยาวหลายบท
- ระบบสงครามเชิงลึก
- ระบบการทูตเต็มรูปแบบ
- คอนเทนต์อาคารจำนวนมาก
- เนื้อเรื่อง cinematic

## 4) Core Loop (ผู้เล่นต้องสัมผัสได้)
1. วางบ้านและถนน
2. จัดการอาหาร/น้ำ/แรงงาน
3. ผลิตและกระจายทรัพยากร
4. ยกระดับบ้านเรือน
5. รับมือเหตุการณ์วิกฤต
6. ผ่านเป้าหมายชนะของด่าน

## 5) Milestone แนะนำ (8-12 สัปดาห์)
- สัปดาห์ 1-2: Prototype loop พื้นฐาน (วางสิ่งปลูกสร้าง + ทรัพยากร)
- สัปดาห์ 3-4: ระบบบ้าน/ความต้องการ + ห่วงโซ่ผลิตชุดแรก
- สัปดาห์ 5-6: ครบ 3 production chains + UI ใช้งานได้จริง
- สัปดาห์ 7-8: ระบบวิกฤต + เงื่อนไขชนะ/แพ้ + ปรับบาลานซ์รอบแรก
- สัปดาห์ 9-10: Polish งานภาพ/เสียงขั้นต่ำ + บันทึกวิดีโอเดโม
- สัปดาห์ 11-12: Playtest ภายนอก + แก้บั๊ก + เตรียมเอกสารขอทุน

## 6) Deliverables สำหรับขอทุน
- Vertical Slice Demo (เล่นได้จริง)
- Gameplay Video 60-90 วินาที
- Pitch Deck 10 หน้า
- Roadmap หลังได้ทุน (Milestone ชัด)
- งบประมาณการใช้เงินแบบแบ่งสัดส่วน

## 7) KPI ก่อนเปิดระดมทุน
- Playtest อย่างน้อย 30 คน
- ผู้เล่นใหม่เข้าใจเกมภายใน 3 นาที
- Session เวลาเล่นเฉลี่ยรอบแรก >= 10 นาที
- Feedback เชิงคุณภาพ: “เห็นความต่างของธีมไทย” อย่างชัดเจน

## 8) ความเสี่ยงหลัก + วิธีลดความเสี่ยง
- Scope บานปลาย -> ล็อกขอบเขตตามรายการ Must Have เท่านั้น
- ระบบเยอะเกินไป -> ทำให้ core loop สนุกก่อน แล้วค่อยเพิ่มระบบรอง
- Demo ไม่ชัด -> ออกแบบ flow เดโมให้จบใน 10-15 นาที
- งานศิลป์ช้า -> ใช้ placeholder ที่คุมโทนเดียวกันก่อน

## 9) Funding Ask (Template)
- ต้องการทุน: [ใส่ตัวเลข]
- ระยะพัฒนาเป้าหมาย: [เช่น 12 เดือน]
- เงินใช้กับ: ทีมพัฒนา, อาร์ต, เสียง, QA, การตลาด
- เป้าหมายหลังได้รับทุน: ส่งเดโมสาธารณะ + เปิดหน้า Steam + ขยายคอนเทนต์หลัก

## 10) Player Journey (MVP Version)
### ช่วงที่ 1: ตั้งเมืองเริ่มต้น (นาที 0-3)
1. ผู้เล่นเห็นแผนที่ริมแม่น้ำและ objective แรก: “ทำให้คนอยู่รอด 50 คน”
2. วางถนน, บ้านเริ่มต้น, แหล่งน้ำ, แหล่งอาหารพื้นฐาน
3. ระบบ tutorial สั้นๆ แนะนำ UI และทรัพยากรหลัก

#### Action Breakdown (ผู้เล่นต้องทำทีละขั้น)
1. กดเริ่มด่านและอ่านข้อความ objective แรก
2. หมุน/ซูมกล้องเพื่อสำรวจพื้นที่วางเมืองที่ติดแม่น้ำ
3. เปิดเมนูถนน แล้วลากถนนหลัก 1 เส้นจากจุดเริ่มต้น
4. วางบ้านเริ่มต้น 4-6 หลังติดถนน
5. วางระบบน้ำพื้นฐาน: ขุดคลองส่งน้ำและวางจุดตักน้ำให้ครอบคลุมบ้านทั้งหมด
6. วางอาคารอาหารเริ่มต้น (เช่น กระท่อมปลา หรือแปลงนาเริ่มต้น) 1-2 จุด
7. เชื่อมอาคารอาหารเข้าถนนเพื่อให้ worker เดินทางได้
8. เปิดแถบทรัพยากรและยืนยันว่าอาหาร/น้ำไม่ติดลบ
9. ปรับความเร็วเกมเป็น x2 และสังเกตคนเข้าบ้านกับการเริ่มผลิต
10. ทำ objective ย่อยให้ครบ: “บ้านเชื่อมถนนครบ”, “น้ำครอบคลุม”, “อาหารเริ่มผลิต”

#### Exit Criteria ของช่วงที่ 1
- ประชากรเริ่มเติบโตอย่างต่อเนื่อง
- อาหารและน้ำอยู่ในสถานะปลอดภัย
- ผู้เล่นเข้าใจ UI พื้นฐานและพร้อมเข้าสู่ช่วงเศรษฐกิจ

### ช่วงที่ 2: สร้างเศรษฐกิจพื้นฐาน (นาที 3-6)
1. ผู้เล่นเปิดห่วงโซ่ข้าว/ไม้ และเชื่อมอาคารเข้าถนน
2. เริ่มมีแรงงานเข้าเมืองและทรัพยากรหมุนเวียน
3. objective ถัดไป: “รักษาอาหารและน้ำให้เพียงพอ 1 รอบฤดู”

#### Action Breakdown (ผู้เล่นต้องทำทีละขั้น)
1. เปิดเมนู Production และเลือกห่วงโซ่ “ข้าว”
2. วางอาคารต้นทางการผลิตข้าวเพิ่ม 1 จุดในพื้นที่เหมาะสม
3. วางอาคารแปรรูปที่จำเป็น (ถ้ามีใน MVP) ให้ใกล้ถนนหลัก
4. เปิดห่วงโซ่ “ไม้” และวางอาคารผลิตไม้ 1 จุด
5. เชื่อมอาคารใหม่ทั้งหมดเข้าถนนเพื่อไม่ให้เกิดสถานะขนส่งติดขัด
6. เปิดหน้าจัดการแรงงาน แล้วปรับคนงานให้พอในอาคารอาหารก่อน
7. วางคลัง/จุดเก็บของพื้นฐาน (ถ้ามี) เพื่อลดระยะทางลำเลียง
8. สังเกตแจ้งเตือนคอขวด เช่น “แรงงานไม่พอ” หรือ “วัตถุดิบค้าง”
9. แก้คอขวด 1 จุดด้วยการเพิ่มบ้านหรือย้ายลำดับความสำคัญแรงงาน
10. รันเวลา 1 รอบฤดูและตรวจว่าทรัพยากรอาหาร/ไม้เป็นบวกต่อเนื่อง

#### Exit Criteria ของช่วงที่ 2
- ห่วงโซ่ข้าวและไม้เดินได้จริงโดยไม่หยุดชะงักยาว
- แรงงานเพียงพอกับอาคารเศรษฐกิจหลัก
- อาหารและน้ำผ่าน objective “พอเพียง 1 รอบฤดู”

### ช่วงที่ 3: ยกระดับคุณภาพชีวิต (นาที 6-9)
1. ผู้เล่นสร้างตลาดและอาคารบริการพื้นฐาน
2. บ้านอัปเกรดจากระดับ 1 -> 2 เมื่อเงื่อนไขครบ
3. เพิ่มอาคารศาสนา 1 จุดเพื่อเสริมค่าศรัทธา/ความสุข

#### Action Breakdown (ผู้เล่นต้องทำทีละขั้น)
1. เปิด objective ปัจจุบันและตรวจเงื่อนไขอัปเกรดบ้านที่ยังไม่ครบ
2. วาง `market` ใกล้กลุ่มบ้านหลักและเชื่อมถนนให้ครบ
3. ตรวจเส้นทางขนส่งจาก `granary/stockpile` ไปตลาดว่าไม่ขาดช่วง
4. วาง `shrine` 1 จุดในย่านบ้านเพื่อเพิ่ม faith/ความสุข
5. เปิดมุมมอง coverage แล้วเช็กว่าบ้านส่วนใหญ่ได้บริการตลาดและศาสนา
6. ปรับแรงงานให้ตลาดและบริการหลักไม่ขาดคนทำงาน
7. เพิ่มบ้าน T1 เล็กน้อย (ถ้าจำเป็น) เพื่อแก้คอขวดแรงงานบริการ
8. รันเวลาและสังเกตบ้านที่เริ่มเข้าเงื่อนไขอัปเกรด T1 -> T2
9. แก้บ้านที่ยังไม่อัปเกรดด้วยการเติม service ที่ขาด (น้ำ/ตลาด/ศรัทธา)
10. ทำ objective ย่อยให้ครบ: “บ้าน T2 ถึงเกณฑ์ขั้นต่ำ” และ “faith ผ่านค่าที่กำหนด”

#### Exit Criteria ของช่วงที่ 3
- บ้านอัปเกรดเป็น T2 ได้ตามจำนวนขั้นต่ำของด่าน
- พื้นที่อยู่อาศัยหลักได้รับ coverage จากตลาดและศาสนาอย่างเสถียร
- เมืองพร้อมรับวิกฤตช่วงถัดไปโดยไม่ติดลบหนักด้านอาหาร/ความสุข

### ช่วงที่ 4: รับมือวิกฤต (นาที 9-12)
1. เกิดเหตุการณ์วิกฤตหลัก (น้ำท่วมหรือภัยแล้ง)
2. ผู้เล่นต้องแก้ปัญหาเฉพาะหน้า: สำรองอาหาร, ปรับแรงงาน, รักษาเสถียรภาพ
3. ระบบแจ้งเตือนช่วยชี้ pain point แต่ไม่แก้ให้ผู้เล่นอัตโนมัติ

#### Action Breakdown (ผู้เล่นต้องทำทีละขั้น)
1. อ่านแจ้งเตือนวิกฤตและดูผลกระทบหลักที่ถูกลดลง (เช่น ผลผลิต, เสถียรภาพ)
2. กด pause ชั่วคราวเพื่อประเมิน HUD: food trend, labor shortage, faith/stability
3. เปิดหน้าจัดการแรงงานและย้ายแรงงานไปอาคารอาหาร/น้ำเป็นลำดับแรก
4. ลดความสำคัญอาคารรองชั่วคราว (เช่น chain ฟุ่มเฟือย) เพื่อกันระบบหลักล่ม
5. ตรวจ coverage น้ำจากคลอง/จุดตักน้ำและแก้จุดที่บ้านเริ่มขาดน้ำ
6. ใช้ stock ที่มีอยู่ผ่านตลาด/โกดังให้วิ่งถึงย่านบ้านหลักก่อน
7. ถ้าทรัพยากรตกหนัก ให้สร้างอาคารฉุกเฉินเพิ่ม 1 จุด (อาหารหรือน้ำ) ในโซนวิกฤต
8. รันเวลาแบบ x1 และเฝ้า alert สำคัญจนค่าอาหารกลับมาไม่ติดลบต่อเนื่อง
9. ติดตามตัวชี้วัดเสถียรภาพ/ศรัทธาไม่ให้ต่ำกว่าเส้นแพ้
10. ผ่าน objective ย่อยของวิกฤต เช่น “อยู่รอดจนจบวิกฤต” หรือ “คุมอาหารไม่ติดลบ X ticks”

#### Exit Criteria ของช่วงที่ 4
- เมืองรอดช่วง active crisis และเข้าสู่ระยะฟื้นตัว
- อาหาร/น้ำกลับสู่ระดับควบคุมได้ (ไม่ติดลบต่อเนื่อง)
- เสถียรภาพเมืองไม่หลุดเกณฑ์แพ้ และพร้อมเข้าสู่ช่วงปิดเดโม

### ช่วงที่ 5: ปิดเดโมด้วยเป้าหมายชนะ (นาที 12-15)
1. เมืองกลับมาเสถียรหลังวิกฤต
2. ผู้เล่นต้องทำเป้าหมายสุดท้าย เช่น ประชากรถึงเกณฑ์ + ศรัทธาขั้นต่ำ
3. จบด่านพร้อมสรุปผล: เวลาเล่น, จำนวนประชากร, ประสิทธิภาพเศรษฐกิจ

### เงื่อนไขแพ้ที่ผู้เล่นต้องรับรู้ชัด
- อาหารติดลบต่อเนื่องเกินเกณฑ์
- ประชากรอพยพจนต่ำกว่าเกณฑ์ขั้นต่ำ
- เสถียรภาพเมืองต่ำมากจนระบบล่ม

### ความรู้สึกที่ผู้เล่นควรได้จาก Journey นี้
- “เริ่มง่าย แต่มีแรงกดดันให้ตัดสินใจจริง”
- “ระบบน้ำ/นาและศรัทธาให้เอกลักษณ์ไทย ไม่ใช่แค่ reskin”
- “อยากเล่นอีกครั้งเพื่อวางผังเมืองให้ดีกว่าเดิม”
